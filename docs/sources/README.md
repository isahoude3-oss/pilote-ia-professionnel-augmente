# Sources — Référentiel des 5 offres cadreIActif

Matériaux de travail utilisés pour construire le [Référentiel des 5 offres](https://claude.ai/code/artifact/c3c451c9-508e-4d69-ae45-e7fbd2e2f90c) et le contenu du site (`nouvelle-charte/`). Conservés ici pour rester accessibles d'une session à l'autre — le scratchpad de travail n'est pas persistant.

## Fichiers

- **`referentiel-5-offres.html`** — copie de sauvegarde du document source publié comme Artifact (Référentiel des 5 offres : L'Actif Augmenté, Le Cockpit d'Intelligence Augmenté, L'Équipe de Communication, Le Créateur de Contenu Augmenté, Les Entreprises à Impact à l'Ère de l'IA).

- **`referentiel-segmentation-global-v4.txt`** — texte extrait du « Référentiel de Segmentation Global V4 » (11 fiches métiers), source des fiches Offre 1 (candidat/repositionnement, rebasée ensuite sur L'Actif Augmenté) et des deux déclinaisons de l'Offre 4.

- **`manager-augmente-20-cas-usage.txt`** — texte extrait du catalogue « Le Manager Augmenté — 20 cas d'usage premium », source de l'Offre 2 (Le Cockpit d'Intelligence Augmenté), resserré à 12 cas dans le référentiel final.

- **`m2i-journalisme.txt`** — texte extrait du support de formation « Intégrer l'IA dans sa pratique journalistique » (M2i), source déontologique de la déclinaison Journalisme/RP/Rédaction de l'Offre 4.

- **`benchmark-finfluenceurs-vinci.txt`** — texte extrait du benchmark réel de 20 finfluenceurs réalisé pour VINCI (méthodologie cadreIActif), utilisé comme cas réel illustrant le Pilier 6 (personal branding / marque employeur) de l'Offre 4.

- **`cadrage-elodie-pilier1.jpg`**, **`cadrage-elodie-pilier2-3-4.jpg`**, **`cadrage-elodie-pilier4-5-6.jpg`** — photos du cadrage de qualification réel avec Élodie, transcrites verbatim dans le Pilier 1 à 6 de l'Offre 4 (structure Aujourd'hui/Demain, citations entre guillemets).

## Note

Les stats et sources externes citées dans le référentiel (Microsoft Work Trend Index 2024, Solidatech × Recherches & Solidarités 2025, Don en Confiance 2021, loi PACTE/OTI) ne sont pas reproduites ici — elles sont citées avec leur référence complète directement dans le document final.
